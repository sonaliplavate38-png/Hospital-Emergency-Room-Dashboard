# Hospital Emergency Room Dashboard

## Project Overview

The Hospital Emergency Room Dashboard is an Excel-based data analysis and reporting project designed to analyze hospital emergency room patient data.

The dashboard provides a monthly view of patient activity, waiting time, satisfaction score, admission status, gender distribution, age group analysis, and department referrals.

## Dashboard Features

- Monthly Patient Analysis
- Number of Patients
- Average Wait Time
- Patient Satisfaction Score
- Patient Admission Status
- Patient Attended Within Time
- Gender Wise Analysis
- Age Group Analysis
- Department Referral Analysis
- Monthly Filtering
- Interactive Dashboard

## Key Metrics

The dashboard displays:

- Total Number of Patients
- Average Wait Time
- Satisfaction Score
- Admitted and Not Admitted Patients
- Male and Female Patient Distribution
- Patient Age Groups
- Department-wise Referrals

## Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Analysis
- Dashboard Design
